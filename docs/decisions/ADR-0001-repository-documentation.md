# ADR-0001：采用轻量研发入口与索引文档

- Status: accepted
- Date: 2026-10-20

## 背景与人类要求

维护者明确要求为 Swarmboard 补齐短入口和文档结构：CLAUDE 仅映射 AGENTS，AGENTS 作为索引，详细规则放入 docs；复用已有主题文档，不引入日报、会议等过程归档体系。现有主题文档已经覆盖架构、安装、会话、通知、界面和测试，缺少统一阅读入口与漂移检查。

## 决定

采用 [AGENTS](../../AGENTS.md) → [总索引](../index.md) → 主题文档的按需阅读路径；[CLAUDE](../../CLAUDE.md)仅含 `@AGENTS.md`。稳定研发规则放入 [rules](../rules/README.md)，持久技术取舍进入本目录。既有主题文档保持主责，不批量移动或复制正文。

研发入口与运行时成员协议、看板个人提示词分开。当前人类目标、成员贡献和即时进度继续由 Swarmboard 管理，不先建 requirements、specs、plans 或过程文档体系；只有具体信息量需要时再扩展。

## 后果与验证

入口更短，增加或修改主题文档时须同步索引；避免同一事实在多个位置失去同步。索引和本地链接的机械检查不能证明语义正确、外部 URL 可用或实际环境验收，仍需源码、测试和人工评审。

[文档维护](../harness.md)规定更新职责；`npm run test:docs` 与 `npm run check:docs` 是入口映射、标题锚点、路径和索引可达性的可重复验证入口，并纳入现有完整检查。
