# 合入、安装与恢复

[安装指南](../setup.zh-CN.md)负责具体命令和路径，[事件工作会话](../event-workers.md)负责暂停、恢复和未知投递语义；本页负责交付顺序与证据门槛。

## 主线交付

1. 核对任务分支的准确 head、基线、作者历史、diff 和适用验证。按人类授权与主线保护通过 PR 合入，不直接强推或绕过必需检查。
2. 必需 CI 必须对应当前候选 SHA；若主线推进导致候选过期，正常合入最新基线、解决冲突并重新验证受影响内容，保留原历史。
3. 使用服务端的 head SHA 条件执行合入并回读合入结果。合入授权不自动授予实际用户环境停机、数据迁移或外部业务写入。

## 包与实际安装

- 固定完整工件、来源提交和校验值；不要混合不同构建来源的服务端、界面与依赖声明。构建成功不代表已安装。
- 更新运行中的用户环境前核对实际安装版本、Schema 兼容、在途回合、原会话及授权范围。保留可恢复备份；未知执行先对账，不按静默时长强杀或重放。
- 局部 widget 更新须独立证明与当前服务端兼容，并明确其范围；不能把局部界面生效描述为完整服务端已升级。
- 安装后核对实际文件、正式接口或资源以及目标行为。真实宿主不可操作或需人类确认时如实报告，不把隔离浏览器证据冒充现场目视。
- 外部成员的准入、进程存活、投递提交、模型消费和成果分别核实。持续通知须证明相关新事件进入原会话、忙碌时排队且结束后续接；不能用游标前进或发送回执代替实际消费。

## 验证记录

[历史验证记录](../verification.md)保存带版本和环境的结果。新增重要发布证据时写明源码、CI、合入、安装与实际验收分别完成到哪里，以及剩余限制。临时状态留在看板和共享上下文，不建立第二套日报或任务进度文件。
