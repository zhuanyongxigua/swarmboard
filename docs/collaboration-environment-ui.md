# 统一设置界面

看板只保留任务管理与共享面板两个顶层页签。右上角齿轮是统一设置入口，取代原连接文字与刷新图标；设置使用原生模态窗口，可通过关闭按钮或 Escape 关闭并将焦点返回入口。设置中的“重新读取设置”读取最新看板和配置，保留未保存草稿与版本冲突保护，不自动重放未确认写入。

设置包括成员上下限、系统提示词、用户提示词与可展开的原资源记录。成员上下限从当前组织读取，独立保存到正式 `pool_capacity` / `POST /api/pool/capacity`，输入必须是 1 到 128 的整数且最少不大于最多。保存携带表单读取时的版本；版本冲突保留草稿，重新读取并核对后才能保存。实际人数与正在收尾人数仍由原概览和容量状态展示，保存新目标不冒充人数立即达标；收缩不强杀在途工作。

系统提示词直接沿用原个人偏好的数据、版本、来源与接口，不创建第二份可写副本。用户提示词使用独立 `user_prompt_read` / `user_prompt_write`，HTTP 为 `GET` / `PATCH /api/user-prompt`。两者均显示当前保存值、版本、来源、更新时间，具有独立草稿、保存与显式清空操作。清空保存新的空版本；后台读取较新版本保留脏草稿并要求显式核对，不自动覆盖或重试。保存请求在途禁止重复提交。

“系统提示词”和“用户提示词”是看板配置名称。两者通过正式成员后续回合的指令快照机制加载，不声称覆盖厂商内置 system 指令、工具审批或项目授权；它们本身不提供执行授权。每轮原子快照与提交前复核的服务端合同见 [board-prompt-settings.md](board-prompt-settings.md)。

原资源定义、ID、版本、类型、能力、访问说明与使用声明原样保留，设置中的“原资源记录”提供只读查看，原共享记录中的资源引用仍能打开并聚焦对应记录。资源不拼接为用户提示词，不因入口迁移而删除、改名或重置。管理 API 仍按既有权限提供，界面不保留第二套旧环境页签或资源编辑表单。

浏览器回归覆盖新入口、两类提示词独立更新/清空、CAS 草稿保护、容量非法输入与冲突、原资源保留、键盘关闭/焦点返回和窄屏。原资源创建/管理的协议测试保留；界面回归改为检查原记录可达和不被迁移改写。组合回归使用隔离真实 HTTP/SQLite，模型派发被禁止。README 双语图片由同一实际界面与合成数据生成，不能据此宣称正式桌面安装或模型实际遵循指令已经验收。
