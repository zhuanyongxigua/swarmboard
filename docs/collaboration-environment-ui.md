# 协作环境界面

“协作环境”页由“可用资源”和“个人偏好”两个独立区域组成。资源为空时只显示资源区空状态，偏好编辑仍可使用。现有资源 ID、展开、编辑、声明与共享记录跳转保持原有含义。

偏好区同时显示当前保存值、版本、来源和更新时间，以及可编辑草稿。来源可如实选择“人类输入”或“主聊天转达”；来源字段只记录声明，不能替代服务端写权限校验。新看板显示空值，不预填任何用户的私人内容。偏好不授予文件、凭据、生产或外派权限，也不覆盖任务约束。

保存与清除都使用当前版本。清除成功后显示服务端返回的新空版本。保存失败不会显示成功；版本冲突会保留草稿、刷新当前保存值，并禁止自动重试。用户核对后可选择“按当前版本继续编辑”，再显式保存；也可放弃草稿并重新读取。后台读到更高版本时同样保留未保存草稿并提示冲突。保存请求在途时禁止重复提交和编辑。

界面通过 MCP `preferences_read` / `preferences_write`，或 HTTP `GET` / `PATCH /api/preferences` 读写。当前值结构为 `{boardId,text,version,source,updatedAt}`；写入为 `{text,expectedVersion,source}`，来源为 `human-input` 或 `main-chat-relay`。读写错误沿现有操作错误协议处理。当前保存值以纯文本呈现，不执行 HTML。

本前端差量的浏览器验收采用合成偏好 API/MCP 回包，并以隔离真实 HTTP/SQLite 服务验证原资源交互。它验证界面合同，不替代后端真实持久化、身份权限、撤销准入、原生成员通知、新会话与忙碌后读取、正式安装或模型验收。整合者必须分别完成这些链路，不能用页面刷新或游标推进证明模型已取得偏好。

组合验收另以真实 HTTP／SQLite 临时服务验证偏好保存与清除、减少及恢复合成成员、进度与资源数据相互保留，以及中英文窄屏显示。README 展示图由同一组合界面和临时数据库生成，个人偏好保持空值；图中任务进度和资源声明均为合成示例，不代表实际模型贡献或真实成员调整。这些隔离验证仍不替代正式宿主安装与模型读取验收。
